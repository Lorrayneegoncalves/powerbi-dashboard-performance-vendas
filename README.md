---

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um dashboard de **Performance de Vendas** no **Power BI**, focado na análise dinâmica do comportamento comercial, acompanhamento de métricas de crescimento e experiência do usuário (UX/UI).

O objetivo é fornecer uma visão executiva clara sobre faturamento, volume de vendas e cumprimento de metas por meio de indicadores visuais e gráficos interativos.

---

## 🎯 Objetivo

Desenvolver um painel estratégico aplicando boas práticas de Business Intelligence, modelagem dimensional e elementos visuais avançados para apoiar a tomada de decisão comercial.

---

## 🚀 Funcionalidades

- Acompanhamento de KPIs comerciais (Faturamento, Margem, Ticket Médio e Meta)
- Visualizações personalizadas (**ImageGrid** e **SimpleImage**) para exibição de categorias
- Animações dinâmicas utilizando **Lottie** para aprimorar a experiência do usuário
- Layout e tema gráfico customizados em JSON e elementos vetoriais em SVG
- Segmentações de dados interativas para análise por período, produto e região

---

## 🛠 Tecnologias utilizadas

- Power BI Desktop
- Power Query (M)
- DAX (Data Analysis Expressions)
- Modelagem de Dados (Star Schema)
- Recurso Lottie Files (Visual Customizado)

---

## 📚 Conceitos aplicados

- Modelagem Dimensional (Star Schema)
- Limpeza e transformação de dados com Power Query
- Criação de medidas DAX para indicadores de vendas
- Contexto de Filtro e Contexto de Linha
- Design de Dashboard Executivo e UX/UI para Analytics
- Storytelling com Dados

---

## 📈 Medidas DAX desenvolvidas

Durante o projeto foram desenvolvidas medidas em DAX para cálculo de métricas comerciais, comparações temporais, percentuais de atingimento de metas e formatação condicional dinâmica, garantindo precisão e performance nas consultas.

---

## 💡 Aprendizados

Este projeto permitiu aprofundar conhecimentos em modelagem dimensional, otimização de medidas em DAX, integração de visuais e temas customizados no Power BI, além da criação de layouts voltados para alta usabilidade e suporte à gestão de vendas.
