## 📑 Sobre o Projeto
Relatório analítico interativo desenvolvido no Power BI com foco em usabilidade (UX/UI), análise dinâmica de dados e métricas visuais avançadas.

## 🛠️ Tecnologias e Recursos
- **Power BI Desktop**: Modelagem de dados relacionais e cálculos em DAX.
- **Visualizações Customizadas**:
  - **Lottie**: Animações dinâmicas para aprimorar a experiência do usuário.
  - **ImageGrid & SimpleImage**: Exibição estruturada de imagens e elementos visuais.
- **Design & Layout**: Tema em JSON (`CY21SU04.json`), fundos vetoriais customizados em SVG e paleta visual exclusiva.

## 📂 Estrutura do Repositório
- `dashboard.pbix`: Arquivo do relatório Power BI.
- `assets/`: Recursos gráficos, marcas, ícones em SVG e imagens.
- `docs/`: Documentação e temas auxiliares.

## 🚀 Como Executar
1. Clone este repositório: `git clone https://github.com/seu-usuario/seu-repositorio.git`
2. Certifique-se de ter o **Power BI Desktop** instalado.
3. Abra o arquivo `.pbix` para navegar pelas páginas e interagir com os filtros.
